# Shahzaib Ahmed Portfolio

Personal portfolio of Shahzaib Ahmed, a MERN Stack Developer based in Hyderabad, Pakistan.

## About the Project

This responsive portfolio introduces Shahzaib, highlights his development experience and skills, and showcases selected projects. Visitors can explore project case studies, download his resume, switch between dark and light themes, and get in touch.

## Technologies Used

**Portfolio:** HTML5, CSS3, and JavaScript  
**MERN stack skills showcased:** MongoDB, Express.js, React.js, and Node.js  
**Other tools and technologies:** TypeScript, Next.js, Git, and GitHub

## Features

- Responsive layouts for mobile, tablet, and desktop
- Mobile navigation with keyboard dismissal
- Dark and light themes with the preference saved in the browser
- Skills and experience sections
- Six projects with individual case studies
- Lazy-loaded project images
- Downloadable resume
- Contact details and a form that opens a prefilled email in the visitor's email application
- Reduced-motion support and keyboard-visible focus styles
